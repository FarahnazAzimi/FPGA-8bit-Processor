# FPGA 8-bit Processor

## Overview

This project presents the design and implementation of an 8-bit processor using VHDL targeting a Spartan-6 FPGA.

The processor was developed as an academic project to demonstrate the design of a simple CPU architecture using hardware description language.

The processor includes several hardware modules such as the Arithmetic Logic Unit (ALU), Register File, Control Unit, Program Counter, Program Memory and Data Memory.

The design was implemented using Xilinx ISE and verified through ISIM simulation.

---

## Main Modules

- Arithmetic Logic Unit (ALU)
- Register File
- Control Unit
- Program Counter
- Program Memory
- Data Memory
- Instruction Decoder
- CPU Top Module
